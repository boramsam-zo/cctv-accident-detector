# 모델 가중치

모델 가중치와 버전, SHA256 검증 방법을 기록하는 공간입니다. 대용량 가중치 파일은 저장소에 직접 추가하지 않습니다.

## 추천 파일

| 파일 | 내용 |
| --- | --- |
| `registry.yaml` | 모델 이름·버전, 가중치 저장 위치, 학습 설정, 기대 입력 형식 |
| `checksums.sha256` | 인계받은 가중치의 SHA256 해시와 파일명 |

가중치는 버전별 S3 경로 등 외부 저장 위치를 `registry.yaml`에 기록합니다. 해시가 일치하는 가중치만 로컬과 Runpod에서 사용합니다.
