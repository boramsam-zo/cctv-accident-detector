# 개념과 설계 선택

## 2026-09-26 — 역할 문서와 공통 계약

PRD는 만들 기능, 역할 문서는 각 영역의 책임, 공통 계약은 연결할 데이터와 상태를 정한다. FE/BE가 같은 job_id/run_id/event_id를 사용하면 후보 영상에 설명과 보고를 나중에 붙여도 한 결과로 연결할 수 있다.

X3D-S는 후보 구간을 판별하고 YOLO는 해당 장면의 객체 정보를 제공한다. YOLO 박스를 X3D 입력으로 넣는 구조로 해석하지 않는다. 후보 시각은 창의 시각이며 정확한 충돌 정답이나 미래 예측 시각이 아니다.

현재 확인한 모델 파일·클래스·코드 설정과 실제 실행·운영 품질은 별개다. 앞으로 실시한 검증만 진행 기록에 완료로 남긴다.
