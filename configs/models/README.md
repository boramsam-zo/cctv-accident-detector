# 모델 설정

YOLO11s와 X3D-S의 재현 가능한 추론 설정을 이곳에 둡니다. 실제 설정값은 모델 인계 후 추가합니다.

## 추천 파일

| 파일 | 내용 |
| --- | --- |
| `yolo11s.yaml` | 가중치 버전, 입력 크기, 클래스 목록 참조, confidence·IoU 기준 |
| `x3d_s.yaml` | 가중치 버전, 프레임 샘플링, 클립 길이, 정규화 값, 충돌 의심 임계값 |

설정값은 인계받은 모델의 검증 결과를 확인한 뒤 기록합니다. 로컬 추론과 Runpod worker가 같은 설정 파일을 읽도록 합니다.
