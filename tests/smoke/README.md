# 스모크 테스트

모델 자산 인계 후 로컬 공통 추론이 샘플 영상으로 실행되는지 확인하는 테스트를 추가합니다.

## 추천 파일

| 파일 | 확인 내용 |
| --- | --- |
| `test_local_inference.py` | 짧은 샘플 영상으로 공통 추론을 실행하고 결과 스키마와 출력 파일을 확인 |
| `test_model_loading.py` | 설정과 가중치를 이용해 두 모델을 로드할 수 있는지 확인 |

테스트에 필요한 샘플 영상의 출처와 저장 위치를 기록합니다. 가중치나 샘플이 없는 개발 환경에서는 필요한 조건을 명시해 실패 원인을 알 수 있게 합니다.
